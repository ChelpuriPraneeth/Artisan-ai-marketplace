# Artisan AI Marketplace

## About
An AI-powered marketplace assistant for local artisans.

## Features
- Helps artisans with product marketing
- Product information management
- AI-powered marketing assistance
- Supports local artisan products

## Technologies
- Google sheets
- Generative AI
- AI-powered marketing workflows

## Project

This project was developed as part of the Generative AI Exchange Program.
It uses Google Sheets and Generative AI to support marketing activities
for local artisans.
